# resume_mani ⚡

> Modern, high-performance portfolio and interactive resume web application built for **Manivanan (Mani)**.

GitHub Repository: [https://github.com/Manivanan0507/resume_mani](https://github.com/Manivanan0507/resume_mani)

## 🚀 Features

- **⚡ Blazing Fast**: Built with React 19 + Vite for instantaneous hot module replacement (HMR).
- **🎨 Modern Aesthetic**: Custom glassmorphism UI, gradient accents, fluid micro-interactions, and smooth animations.
- **🌓 Dark & Light Mode**: Seamless theme switching with persistent CSS custom properties.
- **📱 Fully Responsive**: Optimized for desktop, tablet, and mobile viewing.
- **💼 Interactive Sections**:
  - **Hero & Status**: Quick bio, dynamic experience indicators, and stylized 3D avatar.
  - **Technical Competencies**: Filterable skills matrix (Frontend, Backend, Tools & DevOps) with proficiency indicators.
  - **Experience & Education**: Interactive career and academic timeline.
  - **Featured Projects**: Curated project portfolio cards with source code links.
  - **Printable Resume Modal**: In-browser resume viewer with instant print/save to PDF functionality.
  - **Contact Form**: Interactive message dispatcher with feedback states.

## 🛠️ Tech Stack

- **Framework**: React 19
- **Build Tool**: Vite
- **Styling**: Modern CSS Design System (Glassmorphism, CSS Custom Properties)
- **Icons**: Lucide Icons
- **Typography**: Google Fonts (Outfit, Plus Jakarta Sans)

## 📦 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/Manivanan0507/resume_mani.git
cd resume_mani
```

### 2. Install dependencies
```bash
cd frontend
npm install
```

### 3. Start Development Server
From the root:
```bash
npm run dev
```
Or directly inside `frontend`:
```bash
cd frontend
npm run dev
```

### 4. Build for Production
```bash
npm run build
```
